# سجل الحالات — علاج طبيعي أطفال

تطبيق ويب يعمل بدون إنترنت (PWA). البيانات تُحفظ على الجهاز نفسه (localStorage).

## النشر على GitHub Pages
1. ارفع كل الملفات في هذا المجلد إلى repository جديد (في الجذر).
2. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
3. افتح الرابط `https://USERNAME.github.io/REPO/` من كروم على الأندرويد ← القائمة ⋮ ← «تثبيت التطبيق».

## ملاحظات
- كل جهاز/متصفح له بياناته الخاصة. استخدم «تصدير» و«استيراد» من الإعدادات للنسخ الاحتياطي أو النقل.
- عند تعديل الملفات لاحقاً، غيّر رقم `C='ptapp-v1'` في `sw.js` ليتحدث التطبيق عند المستخدمين.
